`1.0.0` 是 `dsh-ops-pro` 的架构版本：合并上游 `v0.5.6`，并完成本分叉的 R0–R7 重构。

<h3 id="cn-v1.0.0">破坏性变更</h3>

- 移除 `dsh-ops` 命令别名，只安装 `dsh-ops-pro` 命令；所有诊断提示与文档改为 `dsh-ops-pro <command>`。
- 内部模块路径变化：`lib/config*.js` 移到 `lib/config/`，官方工具与 profile 模块移到 `lib/official-tools/`、`lib/profile/`，Windows shell 栈移到 `lib/shells/`，内部兼容转发模块全部移除。公开导出（`dsh-ops-pro/integration`、`./ptc-sdk` 类型）不变。

<h3 id="cn-v1.0.0-changes">变更</h3>

- 合并上游 `v0.5.6`：显式 PTC 披露层级（#985–#989）、未加载工具的区分错误（#997）、宿主版本下限（#701）、内置模式的 `ops_status`（#753）、#1044、#1046、#869。
- OPS-PTC 批量提示改为依据程序实际发出的调用判断，不再做正则代码分析；每类每轮最多一次，每会话最多 3 条（恢复 #1027 上限）。
- PTC SDK 声明中每个工具的数据结构只渲染一次：加载 glob/grep/read_files 的增量从 25,110 B 降到 13,339 B。
- 新的前缀稳定性测试保证选择工具、下一步、下一轮之间非动态段字节不变；`npm run check:host` 在 CI 中约束宿主接触点只能在 `src/adapter/dsh/` 之外按基线增减。
- `npm run env:probe` 列出本机缺失的测试前置条件及其影响的套件。

<h3 id="cn-v1.0.0-fixes">问题修复</h3>

- 恢复上游合并时丢失的 #973 Niubash faces；修复设置插件管理器的包名判断。
- 修复若干在慢速 CI 上会误报的定时器与竞态测试。

`1.0.0` is the architecture release of `dsh-ops-pro`: it merges upstream `v0.5.6` and lands the fork's R0–R7 refactor.

<h3 id="en-v1.0.0">Breaking Changes</h3>

- The `dsh-ops` command alias is removed; only `dsh-ops-pro` is installed and every diagnostic and doc names `dsh-ops-pro <command>`.
- Internal module paths moved: `lib/config*.js` → `lib/config/`, official-tool and profile modules → `lib/official-tools/` and `lib/profile/`, the Windows shell stack → `lib/shells/`; the internal compatibility re-exports are gone. Public exports (`dsh-ops-pro/integration`, `./ptc-sdk` types) are unchanged.

<h3 id="en-v1.0.0-changes">Changes</h3>

- Merge upstream `v0.5.6`: explicit PTC disclosure tier (#985–#989), distinct unloaded-tool errors (#997), host floor (#701), `ops_status` on built-in modes (#753), #1044, #1046, #869.
- OPS-PTC batching notices judge the calls a program actually dispatched instead of regex code analysis; at most once per category per turn and three per session (the #1027 cap is restored).
- The PTC SDK declaration renders each tool's data schema once: loading glob/grep/read_files adds 13,339 B instead of 25,110 B.
- A prefix-stability suite keeps non-dynamic sections byte-identical across selection, next step and next turn; `npm run check:host` ratchets host touch points outside `src/adapter/dsh/` in CI.
- `npm run env:probe` names missing local test prerequisites and the suites each decides.

<h3 id="en-v1.0.0-fixes">Bug Fixes</h3>

- Restore the #973 Niubash faces lost in the upstream merge; fix the settings plugin-manager package check.
- Fix timer and race tests that failed correct code on slow CI runners.
