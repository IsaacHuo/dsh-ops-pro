<h3 id="cn-v1.1.1">包标识改为 scoped</h3>

- npm 包名从无 scope 的 `dsh-ops-pro` 改为 **`@huoweifang/dsh-ops-pro`**。旧名停在 1.1.0 并标记为弃用（deprecated），安装时提示改用 scoped 包；旧包不会从 registry 删除。
- 行 id（`dsh-ops-pro`）、可执行命令（`dsh-ops-pro`）、`ops_*` 工具名、`<DSH_HOME>/dsh-ops/` 状态目录与插件本地的 `dsh-ops` 内部名全部不变，已保存的行设置与覆盖继续生效。
- 公开子路径随包名变化：`@huoweifang/dsh-ops-pro/integration`、`/prompt-injection`、`/ptc-sdk`。
- 安装入口自动迁移：profile 清单里仍有旧无 scope 依赖或 bundle 时，先通过官方 CLI 移除旧名，再安装 scoped 包；移除失败立即中止，不会产生同一行 id 的两个 bundle。

<h3 id="cn-v1.1.1-发布链">发布链与文档</h3>

- 发布链统一按 npm 的 tarball 扁平规则命名：`@huoweifang/dsh-ops-pro` + 1.1.1 → `huoweifang-dsh-ops-pro-1.1.1.tgz`；pack、publish 目录、校验脚本与 release workflow 使用同一规则。
- README 中英文与相关文档更新为 scoped 安装命令、徽章与链接；新增从无 scope 1.1.0 升级的步骤，以及回滚说明。
- README 清理：移除上游横幅、合作方与跑分截图、维护者表等与本项目无关的内容，保留出处与致谢段落。
- 工具面与 1.1.0 相同，没有新增、删除或改名的工具。

<h3 id="en-v1.1.1">Scoped package identity</h3>

- The npm package moves from the unscoped `dsh-ops-pro` to **`@huoweifang/dsh-ops-pro`**. The old name stays at 1.1.0 and is deprecated with a message pointing at the scoped package; it is not removed from the registry.
- The row id (`dsh-ops-pro`), the executable (`dsh-ops-pro`), every `ops_*` tool name, the `<DSH_HOME>/dsh-ops/` state directory and the plugin's internal `dsh-ops` name are unchanged, so saved row settings and overrides keep working.
- Public subpaths follow the package name: `@huoweifang/dsh-ops-pro/integration`, `/prompt-injection`, `/ptc-sdk`.
- The installer migrates profiles: when the manifest still declares the old unscoped dependency or bundle, it removes the old name through the official CLI and only then adds the scoped package. A failed removal aborts the install, so two bundles never land on the same row id.

<h3 id="en-v1.1.1-release">Release chain and documentation</h3>

- Release paths use npm's flattened tarball naming: `@huoweifang/dsh-ops-pro` + 1.1.1 → `huoweifang-dsh-ops-pro-1.1.1.tgz`; pack, the publish directory, the check script and the release workflow all share the rule.
- The READMEs and related docs use the scoped install command, badges and links; they add the upgrade path from unscoped 1.1.0 and a rollback note.
- README cleanup: upstream banners, partner and benchmark screenshots, maintainer tables and other material unrelated to this project are removed, while provenance and credits stay.
- The tool surface is identical to 1.1.0: no tool was added, removed or renamed.
