# 路线图

English: [Roadmap](roadmap.md)。

以下是方向，不是交付日期或承诺；优先级随宿主版本和使用反馈调整。已发布内容见 [CHANGELOG](CHANGELOG.md)，每个版本包含什么由 [PROVENANCE](PROVENANCE.md) 固定。

## 已发布

| 版本 | 内容 |
| --- | --- |
| 0.3.x | 原生 Rust 文件工具与受约束的 PTC 批处理；Windows x64、Linux x64、macOS arm64。 |
| 0.4.0 | Native/PTC 独立投影、作用域发现、类型化 PTC outcome schema、严格 TypeScript 源码。 |
| 0.5.x | 预设行、结果缓存、磁盘报告、Windows Bash 载荷与 `ops_bash` 契约。 |
| 0.6.0 | 首个以 `dsh-ops-pro` 命名、与 `dsh-ops` 并行的发行版。 |
| 1.0.0 | 架构版：单组件行、`src/adapter/dsh` 宿主边界、更小的 PTC outcome schema、批量提示、前缀稳定性套件。 |
| 1.1.0 | 内置 computer-use 运行时（Windows）、只读侧边栏控制台、用量统计。 |

## 后续

### 电脑操控

- 移植上游剩余桌面表面（overlay、后台桌面通道）。
- 要么稳定实验性的 Firefox 通道，要么移除它、改用有文档的 Chromium 附加方式。
- 每次发布在[手动验收](手动验收.md)中记录真实桌面验收结果。

### 平台覆盖

- Windows ARM64 与 Linux ARM64。
- macOS 12 的 `CLONE_ACL` 回退，在本次发布的 macOS 13+ 支持之后处理。

### 工具面

- 扩展有界 DOCX/PDF 子集以外的文档格式。
- 更多 PTC 投影与有界结果形状。

### 发布工程

- `bin/check-release.mjs` 目前要求四个运行时全部就位；改为在本地部分运行时报告缺少哪些目标，而不是直接失败。
- 完成 `bench/cli.mjs` 中已列出但尚未实现的 `tracks` 子命令。
- 可选的 `SHA256SUMS` 分离签名；当前溯源机制是 receipt 加校验和。

## 如何影响方向

用 issue 描述场景和需要的工具调用；流程见[贡献指南](贡献指南.md)。
